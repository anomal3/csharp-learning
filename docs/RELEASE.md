# Выпуск CSharpCoach: установщик и автообновление

## Как выпустить версию
1. Поднять `<Version>` в `src/CsharpLearning.App/CsharpLearning.App.csproj` (например 1.0.1).
2. Если менялись уроки: `dotnet run --project src\CsharpLearning.ContentBuilder -- --offline --fresh` (кладёт `publish\course-vN.db.gz` и `manifest.json`).
3. `powershell -ExecutionPolicy Bypass -File installer\build.ps1` — всё остальное делает скрипт:
   - `--seal` для `content\course.db`: один файл без WAL, VACUUM, проверка целостности, **в базе только контент — таблиц прогресса нет** (иначе сборка падает);
   - `dotnet publish` (win-x64, framework-dependent) в `installer\app`, удаляет `progress.db`, `settings.json`, `course.db.prev`, проверяет, что рядом лежат `refs\core` и `refs\desktop` (без них примеры не скомпилируются без SDK);
   - Inno Setup собирает `installer\Output\CSharpCoach-Setup-<версия>.exe` (~66 МБ, внутри .NET 10 Desktop Runtime);
   - дописывает блок `"app"` (версия, файл, sha256, размер) в `publish\manifest.json`.
4. Залить на хостинг `https://blueboxproduction.ru/csharp/`: `manifest.json`, `CSharpCoach-Setup-<версия>.exe`, `course-vN.db.gz`.
   `manifest.json` должен быть без BOM (скрипт так и пишет; программа BOM тоже переживает).

## Что делает установщик
- Ставит для текущего пользователя в `%LOCALAPPDATA%\Programs\CSharpCoach` — права администратора не нужны, поэтому автообновление идёт без запроса UAC.
- Если на ПК нет .NET 10 Desktop Runtime (нужен и программе, и `dotnet exec` для запуска примеров), ставит его из комплекта; запрос администратора — только для этого шага.
- Прогресс ученика лежит отдельно, в `%LOCALAPPDATA%\CsharpLearning\progress.db`. Установщик его не поставляет и не трогает; при удалении программы спрашивает, удалять ли прогресс (по умолчанию нет).
- Курс в комплекте (`content\course.db`) копируется в данные при первом запуске; если новая программа привезла курс новее, чем локальный, база контента заменяется (старая остаётся как `course.db.prev`), прогресс не затрагивается.

## Как работает автообновление
- При запуске (если включено `AutoUpdate`) программа читает `manifest.json`. Если `app.version` больше версии программы — спрашивает «Установить сейчас?», скачивает установщик, сверяет sha256, запускает его с `/SILENT`, закрывается; установщик обновляет файлы и снова открывает программу.
- Кнопка «Проверить обновление»: сначала новая версия программы, затем новый курс (ставится сразу).
- Проверено локальным «хостингом» (`CSHARP_LEARNING_FEED=http://localhost:8099/`): 1.0.1 → 1.0.2, диалог, скачивание, установка, перезапуск новой версией.
- Не проверено: установка на машину без .NET 10 (рантайм здесь уже стоял, шаг установки рантайма не выполнялся); реальный хостинг (файлы туда не заливались).
