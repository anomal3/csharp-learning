# Оформление CSharpCoach

Строгий тёмный стиль: нейтральные «сланцевые» слои, **один** холодный акцент, цвет — только там, где он что-то значит.
Все цвета живут в `src/CsharpLearning.App/Styles/Theme.xaml` (токены), формы элементов — в `Styles/Controls.xaml`.
В коде и разметке не писать «сырые» hex: брать кисти по имени (`{StaticResource Accent}` и т. д.).

## Слои (от тёмного к светлому)
`Bg` → `BgSoft` (панели) → `CardBrush` → `CardSoftBrush` → `CardHoverBrush`; линии — `Line`, `LineStrong`.
Текст: `Text`, `TextMuted` (пояснения), `TextDim` (мелкие подписи, плейсхолдеры).

## Акцент и статусы
| Тон | Кисти (основной / фон / рамка) | Когда |
|---|---|---|
| Акцент (стальной синий) | `Accent` / `AccentSoft` / `AccentLine`, заливка кнопки — `AccentStrong` | выбранное, главное действие, «в процессе» |
| Good (зелёный) | `Good` / `GoodSoft` / `GoodLine` | верно, пройдено, запуск |
| Warn (янтарный) | `Warn` / `WarnSoft` / `WarnLine` | «дольше обычного», есть замечания |
| Bad (кирпичный) | `Bad` / `BadSoft` / `BadLine` | ошибка, неверно, опасное действие |
| Neutral | `Neutral` / `NeutralSoft` / `NeutralLine` | справочные данные |

Цвет не бывает единственным признаком: рядом всегда значок или слово («Верно» + галочка, «Неверно» + крестик).

## Кнопки (одна главная на экран)
`PrimaryButton` (заливка, «Проверить ответ») › `TonalButton` («следующий урок», «Граф-режим») › `FlatButton` (обычная) ›
`GhostButton` (переключатели панелей) · `RunButton` (зелёная, «Запустить пример») · `DangerButton` (сброс) ·
`SegmentButton` / `SegmentButtonActive` (переключатель C# | Rust).

## Плашки (badge) и выноски (callout)
- Плашка = тонированная подложка + рамка того же оттенка + текст/значок основного тона: `Chip` (нейтральная), `BadgeAccent/Good/Warn/Bad`, `TagChip` (тег).
  Цвет, зависящий от состояния, задаётся конвертером `ToneBrushConverter` (`neutral|accent|good|warn|bad`, параметр `fg|bg|line`).
- Выноска = `ContentControl` со стилем `CalloutNote/Info/Good/Warn/Bad`: мягкий фон и цветная полоса слева.

## «Сколько прошло»
Плашка «прочитано» в шапке урока теплеет по времени (`LessonViewModel.ReadTone`): серая до 3/4 нормы → синяя → янтарная после 1,5 нормы →
красная после 3 норм. Норма — `max(ReadMinutes, 3)` минут; подсказка-объяснение в `ReadHint`.
Плашки «отвечено/верно» (`AnswerTone`): серая → синяя (идёт) → зелёная (всё верно) / янтарная (есть ошибки).
Для проверки без ожидания: переменная среды `CSHARP_LEARNING_TIMESCALE=60` ускоряет часы чтения в 60 раз.
